# ECG-Clock
An ECG-style clock prototype for ESP32 DevKit with a 2.8-inch ILI9341 SPI TFT and DS3231 RTC. One shared graph shows hour and minute markers; the minute marker advances across 0–60, and the hour marker shifts at rollover. Follows IST with AM/PM. Includes Arduino IDE code, a C terminal preview, parts list, and wiring guide.
